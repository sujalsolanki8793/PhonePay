PhonePe Transaction Analytics

This project contains a dataset used to analyze PhonePe transaction data using Power BI.

Dataset:-
The dataset contains transaction-related information that can be used to explore:

Transaction trends
Transaction amounts
Payment methods
Transaction status
State-wise performance
Customer behavior
Successful and failed transactions

Tools Used :-
Power BI
DAX
Excel
Purpose

The dataset is used to create interactive visualizations and identify useful insights from PhonePe transaction data.
